# Текстовая приключенческая игра "Лабиринт сокровищ"

Домашнее задание по предмету "Основы Python"

## Введение

### Что это за проект?

Представьте: вы — отважный исследователь в древнем лабиринте, полном хитрых коридоров, 
скрытых сокровищ и загадок, которые проверят вашу смекалку. Это не просто игра — это ваша 
собственная текстовая adventure игра "Лабиринт сокровищ", где вы программируете правила. 
Игрок (или вы сами в консоли) блуждает по комнатам, собирает артефакты в инвентарь, 
разгадывает ребусы и охотится за главным призом. Всё на чистом Python, 
в консольном стиле — никаких излишеств, только логика и код. 
Начнёте с простого туннеля в одном файле, а закончите хитрой сетью функций, 
где каждый поворот — это тест на мастерство.

### Для чего он нужен?

Проект предназначен для практического закрепления навыков по основам Python и Git. Он 
помогает применить знания на реальном примере: от создания репозитория и отслеживания 
изменений в Git до реализации игровой логики с использованием функций, циклов и 
структур данных. Это отличный способ понять, как соединять базовые концепции в 
конкретный продукт, научиться управлять кодом через Git (коммиты, stash, игнорирование 
файлов) и соблюдать стиль PEP8 с линтером. В итоге вы получите рабочий мини-проект, 
который можно расширять или использовать как основу для дальнейшего обучения.

## Запуск игры

### Установка зависимостей

Проект использует [Poetry](https://python-poetry.org/) для управления зависимостями. 
Если Poetry у вас ещё не установлен, вы можете установить его следующим образом:

```bash
pip install poetry
```

После установки Poetry выполните команду для установки всех зависимостей:

```bash
poetry install
```

или MakeFile:

```bash
make install
```

### Запуск игры

Чтобы запустить игру, используйте Poetry:

```bash
poetry run project
```

или Makefile:

```bash
make project
```

Эти команды запустят главный файл игры, и вы окажетесь внутри текстового мира 
"Лабиринта сокровищ". Приятной игры!
